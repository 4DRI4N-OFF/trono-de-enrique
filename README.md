# El Trono de Enrique

Web de broma para puntuar el baño de un amigo. Una sola página (`index.html`), sin dependencias.

https://4dri4n-off.github.io/trono-de-enrique/

## Reseñas
Se guardan en Supabase (plan gratis). La página solo puede leer y crear reseñas; ocultar o borrar se hace desde el panel.

## Música
No hay ningún archivo de audio en este repositorio. La radio es el reproductor oficial incrustado de YouTube (IFrame Player API), cargado desde youtube.com / youtube-nocookie.com:
- Vídeo: https://www.youtube.com/watch?v=ap5MzFogck8 ("GTA V Radio [East Los FM] Los Tigres Del Norte | La Granja", canal GrandTheftRadioFM).
- La canción pertenece a sus autores y a su sello. Aquí solo se enlaza e incrusta; no se copia ni se redistribuye. Si el vídeo se retira o no permite incrustarlo, el botón abre YouTube.
- Se activa con el primer toque en la página y se puede silenciar con el botón (se recuerda la elección en el navegador).
